Intelligence Router — what you are looking at

One goal of 100 tasks a day streams in from the left as particles. Every task passes through a single intelligence router — the wireframe octahedron — and leaves along one of four glowing lanes. Each lane ends at a model chosen for what it does best and what it costs. The dashboard counts the result live: daily cost, the saving against sending everything to the most capable model, and the monthly revenue of three businesses running on the same system.

The idea borrows from cloud computing. AWS made compute elastic: you stop buying the biggest server for every job and pay for exactly the capacity each job needs. The router does the same for intelligence.

Try it

  • Drag anywhere on the scene to rotate it in 3D. It keeps a little momentum when you let go.
  • Hover an orb, a rule card or the router — that lane lights up and the others step back. Click an orb to keep its lane in focus.
  • Particles move out of the way of your cursor. Double-click returns to the front view.
  • Open the ⚙ controls to switch between eight themes (AETumi Luxe, Sakura Pastel, Kintsugi Gold, Midnight, Cyber Neon, Aurora, Ocean Deep, Monochrome), repaint each lane, and tune speed, particle density, glow, 3D depth and zoom. Esc closes the panel.

The five router rules

  1. Routine → cheap model. Formatting, extraction and simple lookups at about $0.10 a task.
  2. Broad search → K3 Swarm. 300 agents search in parallel instead of one model reading sequentially.
  3. Long context → Kimi K3. Two hundred pages read in one session, without chunking.
  4. Hard judgment → AETumi MAX. The most capable model only thinks deeply where it matters.
  5. Verify every output before it ships — the rule that keeps the other four honest.

How the scene is built

Everything is drawn with Three.js on a 1920×1080 stage. A perspective camera is placed so the z = 0 plane maps pixel-for-pixel onto the stage; every element with depth is compensated so the front view looks exactly like a flat dashboard, and the depth only appears when you rotate. The router is a real 3D octahedron. Each lane is a pair of crossed ribbon meshes along a cubic Bézier curve — so it still reads as a volume from the side — shaded with a soft edge and a dashed centre line that flows toward its model. Around a thousand particles move each frame: the incoming stream, the traffic in each lane and the swirl around the swarm, all pushed aside by the cursor with a soft spring. The lanes drift on a 48-second loop fitted with a Fourier series. All text is real HTML over the canvas, sharp at any size and readable by search engines and screen readers.

Free to learn from and reuse — the source is published on GitHub. Visual concept inspired by @0xkkai.
