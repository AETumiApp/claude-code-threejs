# Claude Code + Three.js with AETumi

AETumi is an AI-native 3D web platform for building production-ready Three.js, WebGL, Next.js and React experiences with AI coding assistants.

This repository focuses on practical workflows for using **Claude Code with Three.js** to build interactive 3D websites, product viewers, scroll-driven experiences and reusable web components.

## What you can build

- Three.js landing pages and hero sections
- Interactive 3D product experiences
- Scroll-driven 3D storytelling
- WebGL effects and animated backgrounds
- React and Next.js 3D interfaces
- React Three Fiber scenes
- AI-assisted refactoring and performance improvements

## Suggested workflow

1. Define the interaction, scene and business goal.
2. Start from an AETumi 3D website, component, scene or prompt.
3. Use Claude Code to inspect the project structure and propose an implementation plan.
4. Build or adapt the Three.js scene inside Next.js or React.
5. Refine camera behavior, lighting, materials, animation and responsive states.
6. Test performance, accessibility and production readiness.
